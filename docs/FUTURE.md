# Future ideas — not in MVP

Do not implement these unless product explicitly expands scope.

- Optional push notifications (copy must stay pressure-free: “Something new is here.” Never streaks or “waiting for you.”)
- Home-screen widgets
- Native Apple / Android apps
- Multiple connections
- Private shared playlists
- “Send a hug”
- Travel mode
- Collaborative photo album
- Memory export
- Anniversary recap
- Handwritten notes
- Scheduled reveal
- Physical prints
- Optional AI-generated monthly summaries (only if users opt in later — never infer feelings)

Notifications, if added later, must remain optional and never imply surveillance or obligation.
